Jawblade Tetris downloads

For the R36S / PortMaster:
  Extract Jawblade-Tetris-PortMaster.zip into the SD card's ROMS/ports folder.
  Keep the included launcher and jawblade-tetris folder together. Launch
  Jawblade Tetris from the Ports menu. PortMaster's shared love_11.5 runtime
  is needed and can be installed through PortMaster.

For a Love2D launcher on a compatible ArkOS build:
  Copy Jawblade-Tetris.love into the device's love2d games folder.

The game uses a 640x480 logical canvas and scales to the handheld display.
